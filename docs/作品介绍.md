# membench · 智能体长期记忆可解释评测框架

**作品介绍文档** ｜ 简称:membench ｜ 面向 openKylin 操作系统

## 一、项目简介

membench 是一套面向 openKylin 操作系统的**智能体长期记忆能力自动化评测框架**。它把智能体的「对话、记忆记录、行动轨迹、文件」统一组织为证据,以**确定性、可解释**的方式,自动评估智能体的六项核心长期记忆能力,一键产出 JSON / Markdown 报告与多维对比雷达图。

它把「智能体记没记住、有没有记错、该不该记」从模糊的直觉判断,变成**可复现、可审计、可量化**的打分,并明确区分三种结果:记住了、误记了、不该记却记了。

## 二、项目背景

2026 年,大模型智能体从实验室走向办公、研发与个人助理。能否**长期、稳定、可控**地记住用户信息,直接决定其可用性:偏好、路径、模板这类稳定信息要记住;临时信息、敏感信息、风险指令又必须排除。openKylin 生态中已出现 KylinBot、Hermes Agent、OpenClaw 等多个智能体框架,但缺少一套**系统级、与操作系统配套**的自动化评测工具。归纳出三大现实痛点:

1. **人工检查难规模化** —— 传统评测依赖人工逐条翻看对话与记忆,无法规模化。
2. **简单问答式验证覆盖不全** —— 无法覆盖冲突更新、相似干扰、边界排除、行动复用等真实场景。
3. **自动评分易语义偏移** —— 难以稳定区分「记住了」「误记了」「不该记却记了」。

## 三、技术架构

评测逻辑与具体智能体完全解耦,核心由「评测运行器 + AgentAdapter 适配层 + 自动评分引擎 + 指标聚合」四部分组成:

```
 评测运行器 runner(加载数据集 → 驱动智能体 → 评分 → 聚合)
      │ 驱动                       │ 评分
 ┌────▼──────────┐          ┌───────▼────────┐
 │ AgentAdapter   │          │ 自动评分引擎     │
 │ reset/on_user/ │          │ scorer(确定性)  │
 │ memory_snapshot│          └───────┬────────┘
 │ action_trace   │                  │ 聚合
 └────┬───────────┘          ┌───────▼────────┐
      │                      │ metrics(六维)   │
 ┌────┴────┬─────────┐       └───────┬────────┘
 │KylinBot │HermesAgent│ ...         │
 └─────────┴──────────┘       ┌───────▼────────┐
                              │ report + radar  │
                              │ JSON/MD/雷达图   │
                              └────────────────┘
```

- **AgentAdapter 适配层**:任何智能体只需实现统一的 4 个方法(reset / on_user / memory_snapshot / action_trace)即可接入同一套评分流程,无需改动评测逻辑。
- **确定性评分引擎**:对每个用例执行「重置 → 播种 → 探针 → 逐条检查」,产出带原因与证据的检查项,结构化区分三类结果。
- **六维指标聚合与可视化**:用例得分聚合为六维 0–100 分,绘制多智能体对比雷达图。

## 四、应用场景

1. **智能体选型对比** —— 在 openKylin 上对 KylinBot、Hermes Agent 等框架做同一基准下的量化对比,辅助技术选型。
2. **版本回归测试** —— 智能体升级记忆模块后自动回归,防止记忆能力回退。
3. **开发调试定位** —— 按六维拆分得分,快速定位某一项记忆能力的缺陷(如「边界识别」漏记敏感信息)。
4. **采购 / POC 评测** —— 为方案评估提供可复现、可审计的量化依据,替代人工主观判断。
5. **开源社区基准榜单** —— 面向社区发布统一评测数据与结果,沉淀长期记忆能力的公开排行榜。

## 五、创新点

1. **可解释的三类判定**:结构化区分「记住了 / 误记了 / 不该记却记了」,每条检查附原因与证据,评分结果可审计、可追溯。
2. **确定性评分、零外部模型**:默认采用确定性关键词 / 键匹配,结果完全可复现,从根上规避 LLM 评分语义漂移;同时预留可插拔判分器接口,可替换为语义判分。
3. **证据统一组织**:将对话、记忆快照、行动轨迹、文件四类证据统一为评分输入,而非只看最终回答。
4. **评测与智能体解耦**:AgentAdapter 接口让任意框架零改动接入,与 openKylin 架构良好集成。
5. **工程落地完整**:一键 CLI、.deb 打包、多维雷达图、自动播放演示脚本,全流程低人工介入。

| 模拟智能体(mock_good / mock_weak) | 已完成 | 100% |

**未实现 / 待完善项**:

1. **真实智能体的 `memory_snapshot()`** —— 需按各框架的实际记忆存储(向量库 / 知识库)覆盖实现,读出当前「可回忆」的键值;这是接入真实智能体唯一待定制点,完成程度约 70%。
2. **更强语义判分器** —— 嵌入相似度与 LLM-as-judge 仅预留接口,未内置默认实现(默认路径为确定性匹配,是有意的取舍)。
3. **评测数据集规模** —— 内置 13 个精心设计的示例用例;另提供确定性生成器 `scripts/gen_dataset.py`,已生成 120 例扩展集(六维各 20 例),可按需扩展到更大规模。

## 七、快速上手

```
# 安装(核心零第三方依赖;雷达图需 matplotlib)
pip install -e .

# 列出可用智能体
membench agents

# 一键运行评测(默认对 mock_good / mock_weak 两个模拟智能体)
membench run

# 使用语义判分(字符 n-gram 基线,零依赖,可插拔)
membench run --scorer semantic
```

运行后在 `results/` 下得到 `report.json`(机器可读完整评分)、`report.md`(人可读报告)、`radar.png`(六维对比雷达图)。
